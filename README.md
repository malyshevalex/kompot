# Kompot (Компот) — редактор для олимпиадных задач на C++

Один файл — одна задача. Код слева, справа тесты (ввод и ответ, импорт из папки),
интерактивная консоль или отладчик. Запуск — как на олимпиаде: вердикты OK / WA / TLE / RE / MLE,
время и пиковая память на каждом тесте.

## Клавиши

| | |
|---|---|
| F5 | запустить; в отладке — продолжить |
| Shift+F5 | остановить |
| F6 | отладка на первом упавшем тесте (или на первом тесте) |
| F9 | точка останова на строке (или клик слева от номера строки) |
| F10 / F11 / Shift+F11 | шаг с обходом / с заходом / выход из функции |
| Ctrl/Cmd + S, O, N | сохранить, открыть, новый файл |

## Запуск и сборка

```
npm install
npm start            # запустить из исходников
npm run dist:win     # release/Kompot-1.0.0-win.zip — распаковать и запустить Kompot.exe
npm run dist:mac     # подписанный и нотаризованный .dmg (нужен профиль notarytool «kletka»)
npm run icon         # перерисовать build/icon.png из build/icon.svg
```

## Выпуск версии и обновления

```
# 1. поднять версию в package.json, закоммитить и отправить
npm run release      # Windows (установщик и zip) и macOS (подписанный, нотаризованный), релиз на GitHub
```

Релизы лежат в [github.com/malyshevalex/kompot/releases](https://github.com/malyshevalex/kompot/releases).
Токен для загрузки скрипт берёт из `gh` для аккаунта `malyshevalex` (`gh auth login`), основной аккаунт gh не переключается.

- **Windows, установщик** (`Kompot-Setup-*.exe`) ставится без прав администратора в профиль пользователя.
  Обновления скачивает сам и ставит при перезапуске. Данные — в `%APPDATA%\Kompot\data`.
- **Windows, zip** — переносная версия, данные в `data` рядом с `Kompot.exe`. Сама себя заменить не может:
  в строке состояния появится «Доступна версия … — скачать». Обновление — распаковать новый zip поверх старого.
- **macOS** — обновления скачивает сам (только подписанные сборки из релизов). Данные — в `~/Library/Application Support/Kompot`.

Сборки для просмотра (`npm run dev:mac`) и запуск из исходников обновления не проверяют.

## Инструменты — свои, системные не используются

Компилятор, подсказки и отладчик Kompot скачивает в свою папку данных (`data/toolchain`)
и использует только их. Удалили папку — удалили всё.

| | Windows | macOS |
|---|---|---|
| Компилятор | GCC 16.2 (w64devkit), 64 МБ | GCC 16.2 (gfortran-for-macOS), 153 МБ |
| Подсказки | clangd 23, 29 МБ | clangd 23, 95 МБ |
| Отладчик | lldb-dap из llvm-mingw, 182 МБ, по требованию | lldb-dap из Command Line Tools |

Компилирует всегда GCC с libstdc++ — как на олимпиадах (`__gcd`, `__lg`, `ext/pb_ds` работают).
clangd и lldb только читают код и отладочную информацию GCC.

На macOS из системы берутся только SDK и debugserver из Command Line Tools: без них на macOS
не работает ни один компилятор и ни один отладчик, и Apple не разрешает распространять их отдельно.

## Как устроено

- `src/main.js` — окно, файлы, компиляция и запуск решений, импорт тестов.
- `src/toolchain.js` — скачивание и распаковка GCC, clangd и отладчика.
- `src/lsp.js` — клиент clangd: подсказки, сигнатуры, ошибки при наборе, семантическая подсветка.
- `src/dap.js` — клиент lldb-dap: точки останова, шаги, переменные, стек.
- `src/runtime/kompot_rt.cpp` — линкуется к решению и при выходе сообщает пиковую память.
- `src/renderer/` — интерфейс: Monaco (редактор VS Code), тесты, консоль, отладка, настройки.
  Компоненты — [Basecoat](https://basecoatui.com) (shadcn/ui без React), поверх — свой слой «стекла и бликов» в `style.css`.
- `src/demo.js` — отладочный сценарий со снимками экрана: `KOMPOT_DEMO=папка npm start`.
